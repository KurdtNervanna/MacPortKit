# Legal and ethical ground rules

Not legal advice — the practices both ports followed so their public repositories
contain nothing that isn't theirs to publish.

## Public (fine to commit and release)

* Your runtime source code (the HLE, host layers, build scripts).
* Your own tools and documentation, including *descriptions* of how the program
  works ("the flight keys are latched by a VBL task at segment 15 offset 0x5028").
* Small factual identifiers needed for interoperability: trap words, resource
  types/ids, addresses and offsets your runtime patches or hooks.
* Screenshots of your port running, for illustration in the README.
* Third-party open-source components under their licences (Musashi, SoftFloat, SDL).

## Private (git-ignore; never publish)

* The program itself in any form: the app file, extracted forks, `segments/*.bin`,
  data resources, regenerated byte-identical assembly (it embeds the original bytes).
* Decompiler output (`combined.c`) — it is a derivative of the program's code.
* Extracted art, sound, music, models, text.
* ROMs, System files, Apple fonts.
* Copy-protection analysis and any bypass. In an HLE port you usually don't need
  one; if the original asks a manual question, it runs like on a Mac. (Falcon MC's
  protection screen never appears under the HLE because of how its roster flow is
  entered — no bypass was written.)

Set up `.gitignore` before the first commit:

```
game/
work/
save/
*.bin
*.rsrc
*.dsk
*.img
*.sit
*.dmg
*.ROM
ghidra_out*/
assets/
```

Before making a repository public, review `git ls-files` and the full history. If
something private was ever committed, rewrite history (`git filter-repo`) and keep a
private backup.

## Releases

Ship the runtime only. The user provides their own copy of the software. For
freeware, cite the author's distribution terms; for commercial titles, point users
to their original media. Don't link to download sites of uncertain legality.

## Credit

Credit the original authors prominently, state that the port is unofficial and not
affiliated with them, and keep their copyright notices intact in the running program.
